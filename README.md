# Mitt Webbprojekt

En enkel och grundläggande webbplats byggd med HTML5.

## Filstruktur
* `index.html` - Huvudsidan för webbplatsen.
* `.gitignore` - Anger vilka systemfiler som ignoreras av Git.
* `.gitattributes` - Säkerställer konsekventa radbrytningar i koden.

## Kom igång
1. Ladda ner eller klona projektet.
2. Öppna `index.html` i valfri webbläsare för att visa sidan.
